PID Control Tuning

A practical guide to tuning PID controllers for robotics applications.

The Basics

PID stands for:

  • Proportional
  • Integral
  • Derivative

Tuning Rules of Thumb

  1. Start with P only
  2. Add D to reduce oscillation
  3. Add I to eliminate steady-state error

Quick Reference

  • Too much P: Oscillation
  • Too much I: Sluggish response
  • Too much D: Noise amplification
